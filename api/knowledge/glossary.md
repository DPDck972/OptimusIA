# Glossário de Terminologias do SIAFI

| Sigla | Nome | Função |
|-------|------|--------|
| UG | Unidade Gestora | Unidade responsável pela execução orçamentária, financeira e patrimonial. Emite empenhos, realiza pagamentos, executa despesas e registra atos contábeis. Possui código numérico e gestão associada. |
| UGR | Unidade Gestora Responsável | Unidade responsável pelo orçamento (responsável orçamentário). |
| PTRES | Programa de Trabalho Resumido | Código que identifica a ação orçamentária, vinculando a despesa a um programa de governo específico. |
| PI | Plano Interno | Código de controle interno da despesa. |
| ND / NDD | Natureza da Despesa / Natureza da Despesa Detalhada | Classificação contábil da despesa pública. Identifica o tipo do gasto. |
| NE | Nota de Empenho | Documento que formaliza o empenho (reserva orçamentária). |
| DH | Documento Hábil | Documento base que gera registros financeiros e contábeis. |
| FR | Fonte de Recurso | Origem do recurso financeiro utilizado (ex: tesouro, convênios, receitas próprias). |
| RAP | Restos a Pagar | Despesas empenhadas mas não pagas até o final do exercício, inscritas para execução no exercício seguinte. |
| OB | Ordem Bancária | Documento utilizado para efetuar pagamentos (transferência bancária). |
| GRU | Guia de Recolhimento da União | Documento para arrecadação de receitas federais. |
| DARF | Documento de Arrecadação Federal | Documento para pagamento de tributos federais. |
| GPS | Guia da Previdência Social | Documento para recolhimento de contribuições previdenciárias. |

## Conceitos Importantes

### Unidade Gestora (UG)
Órgão ou unidade responsável pela execução orçamentária, financeira e patrimonial. Cada UG possui código numérico e gestão associada. Exemplo: UG 153103, Gestão 15234. Uma universidade federal pode ter UG da Reitoria, UG de Hospital Universitário, UG de Campus específico.

### Natureza da Despesa (NDD)
Classificação contábil da despesa pública. Identifica o tipo do gasto orçamentário.

### Fonte de Recurso (FR)
Origem do recurso financeiro utilizado para custear a despesa. Podem ser recursos do tesouro, convênios, receitas próprias, etc.

### PTRES
Programa de Trabalho Resumido. Código que identifica e vincula a despesa a uma ação orçamentária específica dentro do orçamento público.

### Documento Hábil (DH)
Documento base que gera registros financeiros e contábeis no SIAFI. Fundamental para a formalização de lançamentos.

### Evento Contábil
Código que determina quais lançamentos contábeis serão executados automaticamente pelo sistema ao registrar um documento.

### Esfera
Classificação orçamentária que identifica se a despesa pertence ao Orçamento Fiscal (F), Seguridade Social (S) ou Investimento das Estatais (I).

### Modalidade de Licitação
Tipo de processo licitatório: dispensa, inexigibilidade, pregão, concorrência, tomada de preços, convite, concurso, leilão.
